## 📖 Sobre o Projeto

O ****IFMaker Educador**** é uma plataforma web interativa desenvolvida para transformar o manual pedagógico da BNCC Computação em uma experiência digital dinâmica, moderna e responsiva. O aplicativo atua como suporte digital para o projeto de extensão ****"Patrimônio de Nioaque em 3D"****.

O objetivo é apoiar professores na implementação dos eixos da computação (Pensamento Computacional, Mundo Digital e Cultura Digital) através de planos de aula, rubricas de avaliação interativas e checklists de materiais, permitindo que o docente foque no que mais importa: o aprendizado do aluno. Tudo isso conectando a tecnologia maker, a paleontologia e a história de Nioaque-MS à educação básica.

- [x] ****Fase 1:**** Configuração do Ambiente, Layout Base e Estrutura Modular.

- [x] ****Fase 3:**** Desenvolvimento da View de Detalhes e Sistema de Abas.  
- [x] ****Fase 4:**** Interatividade Avançada (Rubricas e Avaliação de Turmas).  
- [x] ****Fase 5:**** Polimento de UI/UX e Configuração exata de Impressão em PDF A4.

---

## 🛠️ Tecnologias Utilizadas

*   ****React (Vite):**** Estrutura reativa de alta performance para componentização da UI.  
*   ****Tailwind CSS:**** Framework utilitário para estilização rápida e responsiva, incluindo formatação dedicada para impressão (`print.css`).  
*   ****JavaScript (ES6+):**** Lógica da aplicação e estruturação de dados em JSON.
