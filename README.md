## 📖 Sobre a Plataforma

O **PATRIMÔNIO DE NIOAQUE EM 3D** é um produto educacional interativo e plataforma web de código aberto desenvolvida pelo **Instituto Federal de Educação, Ciência e Tecnologia de Mato Grosso do Sul (IFMS) – Câmpus Jardim**, no âmbito do **Laboratório IFMaker** com fomento do **Edital nº 054/2025 PROPI/IFMS**.

- **Manual Pedagógico Completo (Zenodo / Acesso Aberto):** [https://doi.org/10.5281/zenodo.24353731](https://doi.org/10.5281/zenodo.24353731)

A plataforma atua como guia prático digital para apoiar professores do **Ensino Fundamental (com foco no 5º ano)** a lecionarem os componentes curriculares da **BNCC Computação** (Pensamento Computacional, Mundo Digital e Cultura Digital) de forma viva, interdisciplinar e contextualizada. 

O projeto une tecnologias de fabricação digital (impressão 3D de artefatos históricos e paleontológicos), metodologias ativas desplugadas e a valorização da identidade e memória regional do município de **Nioaque/MS** (o Vale dos Dinossauros, a Retirada da Laguna na Guerra do Paraguai e a biodiversidade local).

## 🚀 Principais Funcionalidades

### ⏱️ Modo Aula / Timer da Missão (Projeção em Sala)
* **Visão de Projetor em Tela Cheia (`⛶`)**: Interface limpa e de alto contraste, ideal para projetar na lousa, TV da escola ou acompanhar pelo celular.
* **Cronômetro Digital Gigante (`MM:SS`)**: Linha do tempo visual dinâmica baseada na minutagem real de cada etapa da aula (*Aquecimento → Missão Maker → Avaliação*).
* **Controles Práticos de Sala**: Pausar/retomar com a barra de **Espaço**, ajustes rápidos de `+1 min` / `-1 min` durante a regência, alerta sonoro suave (chime harmônico sintetizado via Web Audio API) e **Modo Furtivo (`🤫`)** para silêncio tático nas ilhas.
* **Dicas de Mediação & Modo de Emergência (Plano B)**: Recomendações imediatas para contornar imprevistos caso peças quebrem, o tempo aperte ou os esquadrões travem.

### 📦 Pacote da Aula em 1 Clique (Download em Lote .ZIP)
* **Download Compactado Instantâneo**: Baixa com um único clique o **Plano de Aula Completo**, o **Mapa de Avaliação (Rubrica)**, as **Folhas de Atividades da Missão** e um arquivo de instruções técnicas (`LEIAME_Instrucoes_do_Professor.txt`).
* **Arquitetura Zero-Dependency**: Gerador client-side de arquivos `.ZIP` puro (RFC 1951), sem dependências externas pesadas e com registro de métricas na nuvem.

### 🧭 Onboarding da Caixa Master (Primeiros Passos com o Kit)
* Guia interativo e ilustrado na página inicial orientando o docente:
  1. **Organização dos 8 Potes das Ilhas**: Como distribuir os insumos para até 32 alunos (8 esquadrões de 4) e a *Regra do Inventário de 2 Minutos*.
  2. **Uso e Limpeza no Polaseal**: Boas práticas com canetas de quadro branco, proibição de marcadores permanentes e rotina de limpeza profunda com álcool 70%.
  3. **Conservação dos Artefatos 3D**: Cuidados térmicos com o filamento PLA (não expor ao sol direto ou carros fechados acima de 55°C) e conservação de peças esguias.

### 📱 Funcionamento 100% Offline (PWA - Progressive Web App)
* **Resiliência para a Escola Pública**: Service Worker com estratégia *Stale-While-Revalidate* e manifesto web completo. Se a internet da escola cair, o professor continua acessando todos os roteiros, textos e o timer sem interrupção.
* **Indicador Offline**: Notificação flutuante suave informando a disponibilidade offline de todos os planos.

### ⚡ Performance & Carregamento Sob Demanda (Code Splitting)
* Rotas divididas com `React.lazy()` e `Suspense`. Carregamento inicial leve (~poucos KB), garantindo fluidez mesmo em conexões 3G/4G instáveis.

### 📊 Painel de Impacto em Tempo Real (`/dashboard`)
* Contadores integrados ao **Firebase Firestore** que monitoram visitas ao portal (por sessão), visualizações, downloads de kits, taxa de download, marcados como útil, compartilhamentos, planos aplicados em sala e relatos avaliativos da comunidade docente em tempo real.
* **Alcance Geográfico (IBGE):** Seleção padronizada de Estado (UF) e Cidade nos relatos docentes, exibindo estados e municípios alcançados no Dashboard.
* **Engajamento por Eixo da BNCC, Ranking Top 5 e Exportação CSV:** Visão consolidada por eixo computacional e botão para exportar relatório em `.csv`.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
| :--- | :--- |
| **React 18** | Biblioteca para interfaces reativas, componentização e hooks de ciclo de vida |
| **Vite 5** | Bundler e ambiente de desenvolvimento ultrarrápido com Hot Module Replacement |
| **Tailwind CSS 3** | Estilização utilitária responsiva com suporte a impressão A4 (`@media print`) |
| **PWA & Service Worker** | Cache estático e navegação SPA resiliente para regência 100% offline |
| **Firebase Firestore** | Armazenamento de métricas em tempo real e relatos pedagógicos |
| **Web Audio API** | Síntese de áudio harmônico em tempo real para o timer sem bibliotecas externas |
| **ZIP Utils (Nativo)** | Empacotamento de kits em `.ZIP` client-side direto na memória do navegador |
| **VLibras** | Widget integrado de acessibilidade e tradução para Língua Brasileira de Sinais |

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
* **Node.js** (versão 18 ou superior)
* **npm** ou **yarn**

### Passo a passo
1. **Clone o repositório:**
   ```bash
   git clone https://github.com/skyzinha-chan/ifmaker-patrimonio-nioaque-3d.git
   cd ifmaker-patrimonio-nioaque-3d
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse a aplicação em `http://localhost:5173`.

4. **Para gerar a build de produção:**
   ```bash
   npm run build
   ```
